优途加速器 Windows 使用帮助

Windows 客户端可在智连与自选之间切换；自选模式下可以查看节点延迟、负载并选择具体线路。

Windows 使用重点

  • 智连适合快速连接
  • 自选可查看节点延迟和负载
  • 不要长期关闭系统安全功能

快速使用：只想快速连接可以选择智连；需要指定地区或节点时选择自选，选好线路后点击连接。

Windows 怎么选择节点？

进入自选后，可按国家/地区查看节点。延迟更低通常意味着响应更快，但不要只看单个数字；线路负载、本地网络和目标网站也会影响实际速度。

Windows 安全提示怎么办？

如果 Windows Defender、SmartScreen 或其他安全软件出现提示，先确认安装包来源。不要为了安装或连接而长期关闭系统安全功能。若客户端来自官方渠道但仍被拦截，记录具体提示文字和截图后联系人工客服。

Windows 7 / Server 2008 R2 的旧驱动问题

旧版 Windows 可能遇到 TUN/WinDivert 等驱动加载或签名问题。此类问题只针对 Windows 7、Server 2008 R2 等旧系统，不适用于 Windows 10/11 的常规排障。出现驱动报错时，优先记录错误提示、系统版本和客户端版本，再按对应旧系统方案处理。

连接不上时先做什么？

  1. 确认当前网络本身可以正常上网。
  2. 换一个节点重新连接。
  3. 完全退出优途后重新打开。
  4. 重启 Windows 网络或电脑后再次测试。
  5. 仍失败时，把客户端版本、Windows 版本和报错截图一起提供给客服。
