优途加速器连接不上怎么办？

先确定问题发生在哪一步：客户端打不开、VPN 建立失败、已经连接但没网，还是只有某个网站/应用异常。

先判断是哪类问题

  • 无法建立连接
  • 已连接但没有网络
  • 频繁断开
  • 只有单个服务异常

不要一上来重装。先换节点、重连、切换网络，并记录具体报错；这样更容易判断是线路、系统权限、本地网络还是客户端问题。

一、客户端能打开，但点连接没有成功

先检查

  1. 确认本地网络本身能正常上网。
  2. 换一个节点重新连接。
  3. 手机首次使用时，确认已经允许系统 VPN 请求。
  4. 如果设备上还有其他 VPN/网络代理工具，先退出后再测试。
  5. 完全退出优途并重新打开。

二、显示已连接，但网页或 App 没有网络

排查顺序

  1. 先断开后重新连接。
  2. 切换另一个节点。
  3. 尝试 Wi‑Fi 与移动数据/有线网络互换。
  4. 测试多个网站，判断是整个网络异常还是单个服务异常。
  5. Android 用户如果切后台后断线，检查电池和后台运行设置。

三、连接一段时间后频繁断开

Android 优先检查系统省电、自启动和后台活动权限，具体见Android 后台设置；iPhone/iPad 可检查蜂窝数据、低电量模式，并避免主动强制关闭优途，具体见iOS 使用帮助。网络从 Wi‑Fi 切到移动数据时也可能需要重新连接。

四、只有某个网站或应用不能使用

先测试两个或三个其他网站。如果其他服务正常，基础连接通常已经建立；此时优先更换地区或节点，并检查目标服务自身的地区、账号或风控限制。只有多个网站都异常时，再按“已连接但没有网络”的步骤继续排查。

五、Windows 出现安全或驱动提示

确认客户端来源后再处理安全提示，不要长期关闭 Defender 或其他安全软件。Windows 7 / Server 2008 R2 的 TUN/WinDivert 驱动签名属于旧系统专项问题，应按旧系统情况处理，不要套用到 Windows 10/11。

什么时候需要联系客服？

经过换节点、重连、切换网络和重启客户端后仍稳定复现时，建议联系客服。一起提供客户端版本号、设备和系统版本、故障截图、使用节点及发生时间，排查效率会更高。
